## demo/US-000003 — Show the radial menu in a JavaFX demo application

### User Story

```
AS A developer
I WANT a simple demo application that displays the radial menu in context
SO THAT I can validate layout, styling, and interaction before integrating the component into a larger JavaFX app
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application demo
* **Toolchain / Rules**: Java 25, JavaFX 25, Maven; demo exists to validate the control and documented style customization
* **Phase**: N/A

#### Notes
1. The demo should render the radial menu with a central hub and a minimal set of sample menu items.
2. The demo is intended for visual validation and should not replace a library distribution workflow.
3. The sample application must remain simple, focused, and clearly tied to the component under development.

### Acceptance Criteria

```gherkin
Scenario: demo renders the component
  Given the developer launches the JavaFX demo application
  When the application starts
  Then the radial menu is visible with a centered hub and menu segments arranged around it

Scenario: demo exposes the selection workflow
  Given the demo is running
  When the user hovers and clicks a segment
  Then the menu reflects the selection and the central display updates accordingly
```
