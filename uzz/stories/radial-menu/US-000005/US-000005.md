## radial-menu/US-000005 — Expose CSS customization variables for easy theming

### User Story

```
AS A developer
I WANT to customize the component appearance by defining a few CSS variables
SO THAT I can match my application's design system without modifying component code
```

#### Status
DONE

#### Dependencies
- radial-menu/US-000004

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: Java 21, JavaFX 21, Maven; CSS customization via looked-up colors

#### Notes
1. Define component-specific looked-up color variables for every segment and label state: `-rm-segment-bg`, `-rm-segment-border`, `-rm-segment-bg-hover`, `-rm-segment-border-hover`, `-rm-segment-bg-selected`, `-rm-segment-border-selected`, `-rm-label-fill`, `-rm-label-fill-hover`, and `-rm-label-fill-selected`
2. Provide built-in grayscale defaults with a low-specificity `RadialMenu` type selector so `.radial-menu` rules from a Scene or application stylesheet override them
3. Provide an optional default theme with literal grayscale values and an AtlantaFX integration theme mapping the same variables to root-level `-color-*` tokens (button-scoped tokens are not inherited by a `Pane`)
4. Labels follow the wedge state: hovering or selecting a segment applies the matching pseudo-class to its label group
5. Document all customizable variables in README

### Acceptance Criteria

```gherkin
Scenario: developer customizes radial menu colors via CSS variables
  Given a developer adds CSS rules defining -rm-segment-bg and -rm-segment-border at Scene root
  When the radial menu is rendered
  Then the segments use the custom colors without any Java code changes

Scenario: developer customizes hover and selected backgrounds
  Given a developer defines -rm-segment-bg-hover and -rm-segment-bg-selected on .radial-menu
  When a wedge is hovered or selected
  Then the wedge uses the corresponding custom fill color

Scenario: developer customizes label colors for every state
  Given a developer defines -rm-label-fill, -rm-label-fill-hover and -rm-label-fill-selected on .radial-menu
  When a wedge is idle, hovered or selected
  Then its label uses the corresponding custom text color

Scenario: default colors work when no customization provided
  Given no custom CSS variables are defined
  When the radial menu is rendered with AtlantaFX theme
  Then segments and labels use the built-in grayscale defaults or the AtlantaFX integration theme
  And without any theme they use the built-in gray defaults
```
