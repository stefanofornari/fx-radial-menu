## radial-menu/US-000005 — Expose CSS customization variables for easy theming

### User Story

```
AS A developer
I WANT to customize the component appearance by defining a few CSS variables
SO THAT I can match my application's design system without modifying component code
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: Java 21, JavaFX 21, Maven; CSS customization via looked-up colors

#### Notes
1. Define component-specific looked-up color variables (e.g., `-radial-menu-segment-bg`, `-radial-menu-segment-border`, `-radial-menu-segment-bg-hover`, etc.) with defaults falling back to AtlantaFX button colors
2. Document all customizable variables in README
3. Allow overriding at Scene root or component level via CSS specificity

### Acceptance Criteria

```gherkin
Scenario: developer customizes radial menu colors via CSS variables
  Given a developer adds CSS rules defining -radial-menu-segment-bg and -radial-menu-segment-border at Scene root
  When the radial menu is rendered
  Then the segments use the custom colors without any Java code changes

Scenario: default colors work when no customization provided
  Given no custom CSS variables are defined
  When the radial menu is rendered with AtlantaFX theme
  Then segments use AtlantaFX button colors; without AtlantaFX, they use built-in gray defaults
```
