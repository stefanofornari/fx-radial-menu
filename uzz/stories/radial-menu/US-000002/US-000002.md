## radial-menu/US-000002 — Support hover and click interactions for radial menu items

### User Story

```
AS A user
I WANT the radial menu items to respond visually to hover and click actions
SO THAT I can clearly understand which option is selected and activate a choice with confidence
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: Java 25, JavaFX 25, Maven; styling is handled through documented JavaFX style hooks
* **Phase**: N/A

#### Notes
1. Hover feedback should visually distinguish an item before selection.
2. Click interaction should confirm the selected item and update the central indicator or selected state.
3. Styling hooks must remain configurable through documented JavaFX conventions without changing the core interaction model.

### Acceptance Criteria

```gherkin
Scenario: item highlights on hover
  Given a user moves the pointer across a radial menu segment
  When the pointer enters an item area
  Then the segment displays a hover state that differs from its default appearance

Scenario: click selects an item
  Given a user has a radial menu with multiple item segments
  When the user clicks a specific item
  Then that item becomes the active selection and the selection callback is fired once
```
