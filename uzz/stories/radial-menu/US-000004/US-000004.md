## radial-menu/US-000004 — Integrate AtlantaFX theming for consistent visual style

### User Story

```
AS A developer
I WANT the radial menu to use AtlantaFX theme tokens and default skin
SO THAT it visually integrates with AtlantaFX-styled applications and respects theme changes
```

#### Notes
1. Add AtlantaFX base dependency to pom.xml
2. Use AtlantaFX looked-up color variables (`-color-*`) in radial-menu CSS instead of hardcoded hex values
3. Apply an AtlantaFX theme (e.g., PrimerLight) in the demo application
4. Ensure the component adapts to theme changes (light/dark)

### Acceptance Criteria

```gherkin
Scenario: radial menu uses AtlantaFX color tokens
  Given the radial menu CSS references AtlantaFX color variables
  When an AtlantaFX theme is applied to the scene
  Then the menu segments use theme-appropriate colors for background, border, hover, and selected states

Scenario: demo application applies AtlantaFX theme
  Given the demo application sets an AtlantaFX user agent stylesheet
  When the application launches
  Then the radial menu appears with AtlantaFX-styled colors matching buttons/menus
```
