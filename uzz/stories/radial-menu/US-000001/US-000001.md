## radial-menu/US-000001 — Provide radial menu items and selection callback

### User Story

```
AS A developer
I WANT to configure the radial menu with menu items and a selection callback
SO THAT I can embed the component in a JavaFX application with minimal custom code
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: Java 25, JavaFX 25, Maven; project documentation in `uzz/project/coding_standard.md` and `uzz/project/development_framework.md`
* **Phase**: N/A

#### Notes
1. The component must accept a collection of menu entries and expose them through a reusable JavaFX API.
2. Each menu item should support a label or icon representation and an action payload that can be consumed by the container application.
3. The API should provide a callback or equivalent notification when a user selects an item.

### Acceptance Criteria

```gherkin
Scenario: configure a radial menu with item data
  Given a developer provides a list of menu items with labels and actions
  When the radial menu is created
  Then the component renders each item as a segment in the circular layout

Scenario: selection callback is emitted
  Given a developer has configured a callback on the radial menu
  When a user clicks an item segment
  Then the callback receives the selected item and the menu updates its active state
```
